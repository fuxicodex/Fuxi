# FuXi 数据保护承诺

**Data Protection Commitment**

*最后更新：2026-09-12 · 版本 1.0*

本文档面向全球用户，说明 FuXi 在实践中如何保护数据：它将什么归类为敏感数据、
数据存放在哪里、你拥有哪些控制项、你的权利，以及跨境传输与删除如何运作。

> 相关文档：[隐私政策](PRIVACY_POLICY.zh-CN.md) ·
> [安全白皮书](SECURITY.zh-CN.md) · [合规与责任](COMPLIANCE.zh-CN.md)

## 1. 最小化与问责

我们只处理**为提供产品所必需**的数据，且用于明确说明的目的。

- **使用 FuXi 需要 FuXi 账号** —— 为运营你的账号，仅处理最小的账户数据
  （标识、认证）；不收集不必要的身份数据。
- **零内容上传（默认）** —— FuXi 默认不收集、存储或保留你的代码与对话，也从不
  把上传它们作为使用条件。BYOK 模式下内容直接传输至你所选的提供商；使用 FuXi
  托管模型时，请求仅为服务该次请求而传输，不留存、不用于训练。仅当你显式启用
  `send_conversations` 时，对话内容才会发送给 FuXi（见第 4 节）。
- 本地数据仅为支持会话恢复、记忆与审计而保留。

## 2. 数据分类

| 级别 | 定义 | 示例 | 处理方式 |
|---|---|---|---|
| **公开** | 可公开分享 | 文档、README、版本信息 | 无特殊要求 |
| **内部** | 运营用途，不对外发布 | 内部设计、度量指标 | 最小访问 |
| **敏感** | 泄露会产生风险 | 凭据、API Key、OAuth 令牌 | 加密、最小权限、日志中不含明文 |
| **用户内容** | 你的代码与对话 | 源代码、提示词、会话 | 本地；仅为服务请求而传输；由用户控制 |

> **关键事实**：FuXi **默认不**收集、存储或保留用户内容。在 BYOK 模式下，请求
> 直接发往你选择的提供商；使用 FuXi 托管模型时，仅为服务这些请求而传输。仅当
> 你显式启用 `send_conversations`（第 4 节）时，对话内容才会发送给 FuXi。
> 这使 FuXi 在服务端的数据处理义务降至最低 —— 但这并非声称对所有本地威胁
> 都具有绝对安全性。

## 3. 数据存放在哪里

| 数据 | 位置 | FuXi 能否访问？ |
|---|---|---|
| 配置与凭据（config.yaml） | 用户本地 `~/.fuxi/` | 否 |
| 会话记录 | 用户本地 | 否 |
| 项目记忆文件 | 用户本地，项目内 | 否 |
| 审计日志 | 用户本地 | 否 |
| 请求内容（BYOK） | 用户 ↔ 提供商，直连 | 否 |
| 请求内容（FuXi 托管模型） | 用户 → 模型端点（仅为服务该请求） | 不留存 |
| 账号数据（必需） | FuXi 账号系统 | 仅用于身份认证 |

```
你的机器（本地 —— 我们无法访问）
├── ~/.fuxi/config.yaml      —— 配置与凭据
├── ~/.fuxi/ 会话记录        —— 对话历史
├── 项目记忆文件              —— 跨会话记忆
└── 审计日志                  —— 操作记录

必需的账号流程：
  fuxi login / setup-token   ──▶  FuXi 账号认证（最小数据）

仅为让模型工作而离开设备：
  BYOK：  提示词 + 代码上下文 ──▶  你选择的提供商
  托管：  提示词 + 代码上下文 ──▶  模型端点（仅为服务该次请求；
                                    不留存、不用于训练）
```

**处理规则**

1. **无明文凭据** —— 任何日志、错误信息或截图都不得包含明文密钥。
2. **最小权限访问** —— 本地凭据文件应设为仅属主可访问。
3. **加密建议** —— 为本地数据启用全盘/文件系统加密。
4. **默认最小化** —— 数据仅在运营账号或服务请求所需时才离开设备。
5. **脱敏** —— 分享日志、issue 或 PR 前，先对密钥与个人数据脱敏。

## 4. 隐私控制

FuXi 在本地运行，但有少数功能会使用网络。你可以在 TUI 中管理：

```
/privacy-settings
```

**隐私级别**

| 级别 | 含义 |
|---|---|
| **default** | 遥测已启用 —— 可能发送匿名产品使用信号以改进产品（不含代码、提示词、文件路径或命令输出） |
| **no-telemetry** | 分析/遥测已禁用 |
| **essential-traffic** | 所有非必要网络流量已禁用 |

**开关**

| 设置 | 默认值 | 作用 |
|---|---|---|
| `telemetry` | 在 **default** 级别下开启 | 匿名使用/诊断信号 |
| `crash_reports` | 关闭 | 发送崩溃/错误摘要以帮助修复缺陷 |
| `send_conversations` | **关闭** | 为支持、质量或安全调查发送对话内容 —— 必须由你显式启用 |

默认情况下，FuXi 不会为收集或留存目的发送你的对话内容。只有你显式启用
`send_conversations` 时，对话内容才会为此离开你的设备。启用该开关**并不**
授权用于模型训练；训练用途须另行取得书面同意。

**环境与部署控制**

| 变量 | 作用 |
|---|---|
| `FUXI_DISABLE_TELEMETRY` | 禁用分析/遥测 |
| `FUXI_DISABLE_NONESSENTIAL_TRAFFIC` | 禁用所有非必要网络流量 |
| `FUXI_ANALYTICS_MAX_EVENTS` | 限制分析事件的数量 |
| `--no-update-notifier` / `NO_UPDATE_NOTIFIER=1` | 抑制后台更新检查 |

**其他网络请求**：更新检查仅获取版本元数据；托管模型请求仅在你使用 FuXi 托管
模型时发生；而使用 FuXi 需要账号认证。

## 5. 跨境传输

- **用户内容默认不被收集**：除非你显式启用 `send_conversations`，FuXi 不收集、
  存储或保留你的代码与对话。BYOK 模式下模型请求直接发往你选择的提供商，适用
  该提供商自己的政策与驻留条款；使用托管模型时，请求仅为服务该次调用而传输且
  不留存。
- **账号数据可能被传输**至 FuXi 账号服务部署的区域（使用 FuXi 需注册），并受
  下文所述保障措施的保护。
- 我们如实披露这一点，并建议你查阅所选用提供商的隐私与数据驻留政策。

保障措施：通过 HTTPS/TLS 的加密传输；最小化传输（仅传输请求所需的上下文）；
在 BYOK 模式下由你选择提供商与区域；以及如实披露数据流向。

## 6. 你的权利及如何行使

无论你身处何地，我们尊重以下通用权利：

- **访问与透明** —— 了解我们处理了哪些与你相关的数据；
- **更正** —— 更正不准确的信息；
- **删除** —— 要求删除相关数据；
- **撤回同意** —— 随时撤回基于同意的处理；
- **反对与限制** —— 反对或限制特定处理。

**本地数据由你掌控。** 由于 FuXi 的核心数据存放在你的设备上，你可以立即删除
—— 无需提出请求：

| 数据 | 操作 |
|---|---|
| 本地配置/会话/记忆/审计 | `rm -rf "${FUXI_CONFIG_DIR:-$HOME/.fuxi}"` |
| 账号数据（必需） | 联系我们申请删除 |

**处理时限。** 我们采用适用期限中**最严格**的一个：LGPD 要求 15 天内确认访问
请求，GDPR 要求 1 个月内，CCPA 要求 45 天内。我们的目标是在 **15 天或更短**
内完成。在需要身份验证的情况下，计时从验证完成后开始。若法律允许延期，我们
会告知你原因以及预计答复时间。

**受理渠道。** 使用网站公布的联系方式，非敏感请求也可使用仓库的 issue 跟踪器。
**不要在公开 issue 中发布身份证明文件或其他个人数据** —— 任何需要身份验证的
事项，请使用网站上的私密联系方式。

**我们无法满足的情况。** 法律要求我们保留的数据；以及我们实际并不持有的数据
（如本地数据）—— 我们会如实说明，并引导你自行删除。

**申诉。** 若我们无法满足某项请求，我们会以书面形式说明原因，并提出最接近的
替代方案。若你仍不满意，可通过同一渠道升级，或向你所处司法辖区中受理数据
保护投诉的监管机构投诉。
