## 4. 架构优势：如何天然满足多数要求

- **本地优先 + 自带密钥** = 我们默认**不持有**用户代码与对话 → 多数"收集、
  存储、共享、删除"义务天然消解（无从收集即无从违反）。
- **强制注册但数据最小** = 注册仅处理运行账号所需的最少账户数据；不上传
  任何内容。
- **显式权限 + 审计** = 满足"人在环中""可问责"。
