# FuXi 透明度报告

**Transparency Report**

*最后更新：2026-09-12 · 版本 1.0 · 层级：L5 信任*

本报告定期披露 FuXi 在安全、隐私与政府请求方面的真实情况。**核心事实**：
本地优先架构使我们的可披露数据天然最小。

**报告期间**：本期为首次发布（2026-09-12）。刷新周期：每半年（或在重大
变更时）。统计数字仅在确有需要公开报告的事项时披露；本期相关单元格以事实
状态说明，不编造数字。

## 4. 我们的立场

- 我们不主动收集可被"索取"的用户内容；
- 面对合法请求，我们只能在**实际持有**的极小范围内响应；
- 我们公开披露我们的处理范围，以便用户与监管方理解。
