# FuXi 信任中心

**Trust Center**

*最后更新：2026-08-23 · 版本 1.0 · 层级：L5 信任*

本页是 FuXi 面向用户与企业的**安全与隐私可信披露**入口，集中呈现核心事实、
承诺与资源。

---

## 1. 一句话总结

**FuXi 本质安全、保护用户**：本地优先、自带密钥、凭据不上传、默认不收集
代码与对话，尊重全球法律与用户行为。

---

## 2. 核心事实速览

| 维度 | 事实 |
|---|---|
| 数据驻留 | 代码、配置、凭据、会话默认留在你的设备 |
| 密钥 | 仅存本地，不上传、不复制 |
| 内容收集 | 默认不收集代码与对话 |
| 强制注册 | 否，无需账号即可使用核心功能 |
| 命令安全 | AST 分类器 + 权限提示 + 审计日志 |
| 更新 | SHA-256 校验 + 原子替换 |
| 遥测 | 无隐藏后台上传 |
| 认证声明 | 不虚构任何第三方认证 |

## 5. 我们的承诺（可验证）

1. 默认本地、最小收集、透明披露；
2. 命令与权限可审、可控、可撤销；
3. 更新可校验；
4. 不虚构认证、不夸大能力。
