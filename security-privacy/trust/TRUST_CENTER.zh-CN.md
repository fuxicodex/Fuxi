# FuXi 信任中心

**Trust Center**

*最后更新：2026-09-12 · 版本 1.0 · 层级：L5 信任*

本页是 FuXi 面向用户与企业的**安全与隐私可信披露**入口，集中呈现核心事实、
承诺与资源。

---

## 1. 一句话总结

**FuXi 本质安全、保护用户**：本地优先、自带密钥、凭据不上传、默认不收集
代码与对话，尊重全球法律与用户行为。

---

## 2. 核心事实速览

| 维度 | 事实 |
|---|---|
| 数据驻留 | 代码、配置、凭据、会话默认留在你的设备 |
| 密钥 | 仅存本地，不上传、不复制 |
| 内容收集 | 默认不收集代码与对话 |
| 强制注册 | 是 —— 使用 FuXi 需要 FuXi 账号 |
| 内容上传 | 无 —— 零内容上传（代码/对话不被收集、存储或保留；不用于训练） |
| 命令安全 | AST 分类器 + 权限提示 + 审计日志 |
| 隐性保护 | 默认开启，无需配置（见[安全白皮书 §5](../SECURITY.zh-CN.md)） |
| 更新 | SHA-256 校验 + 原子替换 |
| 遥测 | 无隐藏后台上传；存在的分析均可关闭（[隐私控制](../PRIVACY_CONTROLS.zh-CN.md)） |
| 认证声明 | 不虚构任何第三方认证 |
| 全球法律 | 对齐主要隐私/AI 法律；风险在[全球法律风险地图](../compliance/GLOBAL_LAW_MAP.zh-CN.md)中披露 |

## 5. 我们的承诺（可验证）

1. 默认本地、最小收集、透明披露；
2. 命令与权限可审、可控、可撤销；
3. 更新可校验；
4. 不虚构认证、不夸大能力；
5. 面向开发者，不面向不满 14 周岁儿童 —— 14–17 岁需父母或监护人；不做行为
   广告或画像；
6. 如实的能力边界 —— FuXi 是工具而非顾问；输出可能出错，依赖前须先审阅。
