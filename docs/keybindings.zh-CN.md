# 键盘快捷键

FuXi 终端 UI 的快捷键速查。在空提示符开头输入 `/` 可打开命令面板，其中列出
许多相同的操作。

> macOS 提示：`Alt` 指 **Option** 键。如果你的终端把 Option 当作"组合键"
> （macOS 终端 / iTerm 关闭了"Option 作为 Meta"），部分 `Alt+` 快捷键可能
> 无法送达 FuXi —— 请改用对应的 `Ctrl+X` 组合键。

## 提示词编辑器

| 按键 | 作用 |
|---|---|
| `Enter` | 发送消息 |
| `Ctrl+J` / `Shift+Enter` | 插入换行 |
| `↑` / `↓` | 上一条 / 下一条提示词历史 |
| `Ctrl+R` | 反向搜索提示词历史 |
| `Ctrl+V`（macOS/Linux）· `Alt+V`（Windows） | 从剪贴板粘贴图片作为附件 |
| `/` | 打开命令面板（在空提示符开头） |
| `Esc` | 取消 / 关闭当前弹窗 |

## 对话 / 转录

| 按键 | 作用 |
|---|---|
| `Esc` | 取消当前操作或关闭弹窗 |
| `↓` / `j` · `↑` / `k` | 向下 / 向上滚动 |
| `Shift+↑` / `Shift+↓` | 跳到上一条 / 下一条用户消息 |
| `Ctrl+U` / `PgUp` | 向上滚动半页 |
| `Ctrl+D` / `PgDn` | 向下滚动半页 |
| `Space` / `Ctrl+F` | 向下滚动一页 |
| `b` / `Ctrl+B` | 向上滚动一页 |
| `g` / `Home` | 跳到对话顶部 |
| `G` / `End` | 跳到对话底部 |
| `Ctrl+T` | 循环切换内联任务 / 队友面板 |
| `Tab` | 切换侧边栏 |
| `Shift+Tab` | 循环切换权限模式（default → acceptEdits → plan） |
| `c` | 复制选中的卡片 |
| `p` | 复制选中卡片的输入 |

## 全局

| 按键 | 作用 |
|---|---|
| `Ctrl+C` | 中断或退出 |
| `Ctrl+L` / `Alt+P` | 打开模型选择器 |
| `Ctrl+G` | 在 `$EDITOR` 中打开提示词 |
| `Ctrl+Shift+P` | 快速打开 —— 模糊文件查找器 |
| `Ctrl+Shift+F` | 全工作区搜索 |
| `Ctrl+S` | 把当前提示词暂存到一边 |
| `Ctrl+W` | 打开工作流 |
| `Ctrl+Y` | 拉取 —— 插入最近被删除的文本 |
| `Alt+Y` | 拉取循环 —— 遍历删除环 |
| `Ctrl+Z` | 挂起 FuXi 到后台 |
| `Alt+O` | 切换快速模式 |
| `Alt+T` | 切换模型的思考生成 |
| `Alt+M` | 折叠 / 展开侧边栏 MCP 区域 |
| `Alt+V` | 按住说话的语音捕获 |
| `Ctrl+_` / `Ctrl+Shift+-` | 撤销最后一次提示词编辑器编辑 |
| `Esc` `Esc`（双击） | 回退对话到之前的节点 |

## `Ctrl+X` 组合键

`Ctrl+X` 进入组合键前缀；下一个按键完成操作。

| 组合 | 作用 |
|---|---|
| `Ctrl+X` `Ctrl+L` | 重绘屏幕（外部清屏后恢复） |
| `Ctrl+X` `Ctrl+O` | 切换快速模式 |
| `Ctrl+X` `Ctrl+T` | 切换思考 |
| `Ctrl+X` `Ctrl+P` | 快速打开 |
| `Ctrl+X` `Ctrl+F` | 工作区搜索 |
| `Ctrl+X` `Ctrl+V` | 语音捕获 |
| `Ctrl+X` `Ctrl+W` | 工作流 |
| `Ctrl+X` `Ctrl+E` | 外部编辑器 |
| `Ctrl+X` `Ctrl+K` | 终止正在运行的 agent |

## 弹窗

| 按键 | 作用 |
|---|---|
| `Tab` / `Shift+Tab` | 在项目间移动焦点 |
| `↑` / `↓` | 选择项目 |
| `Enter` | 确认 |
| `Esc` | 取消 |
| `y` / `n` | 确认提示中的是 / 否 |
